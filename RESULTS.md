# Results

All numbers below come from runs on English Premier League 2023-24 data (100 matches, 20 teams).
LLMs: Gemini 2.5 Flash (`gemini-2.5-flash`) and `openai/gpt-oss-120b` served by Groq.
The paper used GPT-4.1-mini. Run dates: 2026-11-18.

## Key findings

- **The paper's main result reproduces exactly.** Manual-only 7/16, manual-expanded 16/16 and manual + LLM 16/16 (+128.57%), batch by batch, using the authors' models, tests and anomalies.
- **Free LLMs match GPT-4.1-mini on the paper's benchmark.** Manual tests plus tests generated by Gemini or by gpt-oss-120b also catch 16/16.
- **Most generated tests add nothing.** Pruning keeps 18 of 58 candidate tests (Gemini) and 19 of 54 (gpt-oss-120b) with no loss of detection across 188 mutated databases, so roughly two thirds of the tests can be removed. The paper's manual audit judged 16 of 25 tests redundant or low-value.
- **A minimal test set does not transfer to unseen damage.** When the minimal set is chosen without seeing out-of-range, orphaned-row and date-shift damage, it catches only 33.3% (Gemini) and 40.0% (gpt-oss-120b) of what the full candidate set catches on that damage. Rotating every operator out in turn gives an average of 46.0% (Gemini) and 44.0% (gpt-oss-120b). The expectation that "the full set adds no extra coverage" does not hold on unseen mutation types.
- **Detection on the paper's benchmark is stable, the tests are not.** Over five trials manual + LLM is 16/16 every time (frozen and freshly regenerated), as in the paper, yet each fresh generation shares only 78-94% of its tests with the first one, and a changed prompt dropped out-of-range coverage from 24/24 to 12/24.

## 6. Stability (five trials)

Two kinds of repetition, following the paper's five-trial protocol:
- **Frozen**: the same generated test set, anomaly experiment run five times.
- **Fresh**: tests regenerated from scratch for every trial (new LLM call per model), then the anomaly experiment.

Paper: 7/16, 16/16, 16/16 in all five trials.

| LLM | Mode | Manual-only | Manual-expanded | Manual + LLM |
|---|---|---|---|---|
| gpt-oss-120b | Frozen, 5 runs | 7, 7, 7, 7, 7 | 16, 16, 16, 16, 16 | 16, 16, 16, 16, 16 |
| gpt-oss-120b | Fresh, 5 trials | 7, 7, 7, 7, 7 | 16, 16, 16, 16, 16 | 16, 16, 16, 16, 16 |
| Gemini 2.5 Flash | Frozen, 5 runs | 7, 7, 7, 7, 7 | 16, 16, 16, 16, 16 | 16, 16, 16, 16, 16 |
| Gemini 2.5 Flash | Fresh, 5 trials | 7, 7, 7, 7, 7 | 16, 16, 16, 16, 16 | 16, 16, 16, 16, 16 |

How much the generated test sets change between fresh trials:

| LLM | Tests kept per trial | Identical to trial 1 |
|---|---|---|
| gpt-oss-120b | 52, 53, 56, 53, 55 | 52, 47, 46, 46, 47 |
| Gemini 2.5 Flash | 53, 67, 62, 62, 53 | 53, 52, 50, 53, 50 |

- **Detection on the paper's benchmark is fully stable**, for both LLMs and in both modes, matching the paper.
- **The test sets themselves are not stable.** Between 6% and 22% of the tests in a later trial are not in trial 1 (gpt-oss-120b keeps 46-47 of trial 1's 52; Gemini keeps 50-53 of trial 1's 53, and its set size ranges from 53 to 67). The 16-anomaly benchmark is too coarse to show this; the mutation results in sections 3-5 do show it (out-of-range coverage 24/24 vs 12/24).
- The frozen runs use the latest test sets (after the date-range change), so manual + LLM is 16/16 for those sets as well.
- The first Gemini attempt at fresh trial 5 stopped because the Gemini API returned 503 (model overloaded); the rerun completed all five trials (trials 1-4 came from the reply cache, so they are the same generations).

## Notes on comparability

- The paper judged usefulness by hand against 16 anomalies; here it is computed automatically against 188 mutated databases, so the counts are comparable in spirit, not one to one.
- Data differs slightly from the paper's setup: the same 100 matches were fetched round by round with TheSportsDB's current free key, and status `FT` is mapped to `Match Finished`.
- LLM calls use temperature 0.
